# Architecture Explorer

The public product contains the [five final ECS diagrams](CURRENT-INDEX.md).
Their JSON sources, official Archify 3.1.0 HTML, reading sheets, licenses and
pinned generation/provenance files are unchanged. Original generation receipts
can mention historical comparisons performed at their date; those older diagrams
are no longer shipped or maintained. Retrieve them from Git commit
`5b13b448c328241e02ee1432fba221e675e85810` if needed.

Run `node --test scripts/diagrams/test-diagrams.mjs` to verify the current
artifacts, source citations and reading-sheet integrity. See the current index
for the existing official generation procedure. No artifacts were regenerated
for the documentation cleanup.
